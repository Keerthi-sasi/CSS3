CSS Color System

In CSS, the color system is used to set the color of text, backgrounds, borders, and other elements.

Color Names

Use predefined names like red, blue, green, etc.

HEX colors

Use hexadecimal values such as #ff0000 for red.

RGB/RGBA

Define colors using red, green, blue values, with RGBA also supporting transparency.

HSL/HSLA

Defines a color using Hue, Saturation, and Lightness with an Alpha value for transparency

CSS text properties

CSS text properties are used to control the appearance, alignment, spacing, and decoration of text on a webpage.
